# Product Release Notes

## Platform Version 3.2



**Release Date:** March 28, 2026  

**Product:** Asteron Enterprise Platform  

**Audience:** Business Users, Customers, Partners



---



## Overview



Version 3.2 of the Asteron Enterprise Platform introduces performance improvements, enhanced security controls, and usability enhancements designed to improve overall user experience and operational efficiency. This release focuses on stability, compliance readiness, and feature refinements based on customer feedback.



---



## Key Highlights



- Improved system performance across core workflows

- Enhanced security and access control features

- New reporting capabilities for business users

- Multiple bug fixes and stability improvements



---



## New Features



### 1. Enhanced Access Management



Administrators can now define role-based access policies with greater flexibility. This improvement allows organizations to better align system permissions with internal governance and compliance requirements.



**Business Benefit:**  

Improved security posture and reduced risk of unauthorized access.



---



### 2. Advanced Usage Reports



A new set of built-in reports provides insights into platform usage, user activity, and feature adoption.



**Business Benefit:**  

Enables data-driven decision-making and better operational visibility.



---



## Performance Improvements



- Reduced average page load times by approximately 25%

- Optimized background job processing for large datasets

- Improved scalability for concurrent users



These enhancements result in smoother system performance during peak business hours.



---



## Security Enhancements



- Strengthened password policy enforcement

- Improved audit logging for administrative actions

- Updated encryption standards for data at rest



These changes support compliance with common enterprise security standards.



---



## Bug Fixes



- Resolved intermittent login issues reported by some users

- Fixed inaccuracies in exported CSV reports

- Addressed minor UI alignment issues on the dashboard



---



## Known Limitations



- Custom reports created in versions earlier than 3.0 may require validation after upgrade

- API rate limits remain unchanged in this release



---



## Upgrade Notes



- No downtime is required for customers on version 3.1

- Customers on versions earlier than 3.0 should review the upgrade documentation prior to updating
