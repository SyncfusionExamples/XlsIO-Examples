# Convert a Named Range to an Image

This sample demonstrates how to convert a named range in an XLSB workbook to a PNG image using Syncfusion XlsIO and XlsIORenderer.

## Requirements

- Syncfusion.XlsIO
- Syncfusion.XlsIORenderer

## Process

1. Opens the `Sample.xlsb` workbook.
2. Retrieves the named range `Range1`.
3. Converts the named range to an image.
4. Saves the rendered image as `Output.png`.

## Input

Place the `Sample.xlsb` workbook in the `Data` folder and ensure that it contains a named range called `Range1`.

## Output

The converted image is saved as:

`Output/Output.png`
